# genieacs-docker

This repository is intended for GenieACS deployment configuration. The proposed
ISP billing service is a separate application; its repository-neutral project
structure and initial scope are documented in
[docs/billing-service-structure.md](docs/billing-service-structure.md).

A standalone, static UI/UX prototype is available at
[billing-ui/index.html](billing-ui/index.html). Open it directly in a browser;
it uses sample data in memory and is not connected to a backend. Its MikroTik
and GenieACS pages are UI mockups only and do not connect to or change devices.
